# dsh-meme 宣传片制作基准

模式：自主自由创作。用户要求“你直接装个这个，然后推广一下 dsh-meme”，以直接完成为授权，自主选择执行路线。

## 产品简报与需求决策

受众是 DSH 用户与喜欢表情包的 AI 玩家。片子用于 B 站、项目主页及社区分享；交付 1920×1080、30fps、36 秒中文 MP4 和可编辑工程。重点是普通用户操作：自己点图发、让 AI 回图、上传后学图、管理和分享图库。没有公开发布平台的清单，本次完成宣传素材与发布文案。

功能证据：本工程 README.md、client.js、index.js、panel.html。安装口径：DSH → 插件 → 添加插件 → dsh-meme。学图需要支持图片输入的模型。图库投稿需提交审核，导出不等于市场收录。

| 要求 | 执行选择 | 验证 |
|---|---|---|
| 推广真实产品 | 使用 docs 中已有真实产品截图、内置表情，不重建产品 UI | 原文件、素材清单与画面核对 |
| 普通用户能理解 | 每镜一个功能，72px 以上主标题、64px 解说 | 手机尺寸缩图检查 |

## 视觉方向

检查过三个方向：纸墨风、深色科技风、产品原生蓝白风。选择蓝白风，因为 panel.html 的浅色 tokens 是 #f5f5f7 / #ffffff / #1c1c28 / #6b6b7b / #4f6ef7；原生字体 system-ui、Microsoft YaHei，8–10px 圆角。视频放大到 28–36px 圆角，保留产品字体与配色。现有截图是深色主题，在白底展示窗口内完整保留，说明产品也支持深色外观；不把它涂改成浅色 UI。

标题 104–120px，说明 64–68px，辅助 40–44px。信息靠左，主体靠右，12-column 思路、96px 安全边距。动效亲和友好：26f 入场，≤1.04 过冲；稳定相机，不震屏、不群发光效。结尾功能元素向中心归位，CTA 至少停留 2 秒。

## 音频与验收口径

音乐未由用户指定，按 pipeline 阶段 6 和 music-beat-sync §0 采用内容先行时间线，不强制逐切点卡拍。House Vibez — Lily J（Mixkit Music Free License）低音量铺底，首尾淡入淡出；清晰的实体快门与转场音钉在元素入场/落定，音效时长显式限制。两版使用 bgm inputProp 从同一时间线渲染。无旁白，用大字解说承担信息。

对声音攻击峰做测量；SFX 稀疏，没有整画面拍点冲击。A9 不以未测常数假装精确同步，渲后测尖锐探针并记录限制。

有意识适配审美准则：Q7 的暗色金属环境不适用于产品亲和方向；Q8 保留功能合影，不使用舞台粒子；C3 的衬线荧光笔不适用于原生无衬线蓝白系统；字幕属于屏幕解说层，并非 3D 画内注记。

制作放行：功能完整、数据范围明确、时间线与视觉方向一致；静态 styleframe 验证后开始实现。交付前由独立审查 agent 检查成片、关键帧、功能与素材。
