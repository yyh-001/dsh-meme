# dsh-meme 图库维护手册

维护 = 看(meme_list)+ 改(meme_update);删除只在管理面板（不提供 agent 删除，误删成本高）。

## 1. 查清单：meme_list

- 参数：`q`(关键词，空格分隔多词全命中，按 描述/关键词/文件名 子串筛)、`tag`(分类)、`packId`(只看某个图库)、`limit`(默认 20，最大 100)。
- 默认范围 = **所有启用中的图库**；每行带 `library`(所属图库)、`tag`、`caption`、`keywords`、`path`。
- path 约定：**当前激活库不带前缀，其它库带 `packId/` 前缀**。把这个 path 原样传给 meme_update 一定能定位。
- 清单长就分批：先 `q` 粗筛，再对可疑的几条逐条看。

## 2. 改元数据：meme_update

- 参数：`path`(必填，用 meme_list/send_meme 候选里的原样) + `tag`/`caption`/`keywords` 至少一项。
- 只改索引，不动图片文件；没给的字段保留原值。
- 兼容三种 path：包前缀相对路径、当前库相对路径、绝对路径（IM 模式候选给的是绝对路径）。

## 3. 查重复

meme_list 没有内建去重，手动思路：

1. `meme_list` 按 `q` 拉同主题清单（如 `q=开心`）；
2. 对比 caption 相近/文件名模式相同的行（上传落盘的文件名都是 `时间戳_随机数.扩展名`，人工收藏的常保留原名）；
3. 确认重复后告诉用户哪几张是重复的，**让用户在管理面板里删**（agent 不执行删除）。

## 4. 手动拷贝的图片入库（扫描新增）

用户把图片文件直接放进图库目录时，面板里不会显示（索引只认 index.db）：

1. 文件放到图库目录的子目录里，**子目录名就是分类**（如 `memes/work/躺平.gif` → work）；散在根目录的会归 `misc`；
2. 管理面板 → 图库页 → 「扫描新增」；或调管理接口 `scanPack`；
3. 描述默认取文件名，入库后用 meme_update 补描述/关键词。
4. **动图 GIF 只能走这条路或面板上传保真**——聊天附件通道会把 GIF 压成单帧，这是宿主行为，无法还原。

## 5. 批量整理的推荐流程

```
meme_list (limit=100)          # 全量拉一遍看分布
  → 按 tag 归类出问题清单      # 错分类/缺描述/疑似重复
  → 逐条 meme_update           # 改分类/补描述（一次改一张，失败不影响其它）
  → 输出整理报告给用户         # 改了什么、建议手删哪些重复
```

注意：改的是**当前激活库以外的库**时也可以直接改（path 带前缀就行），不必让用户先切库。
